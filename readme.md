--

The expression 3+4+5+6 is a sum (also called a summation).

Those addends are consecutive integers, so they form an arithmetic sequence, and the sum itself is an arithmetic series. Its value is 18.

--

A summation is the addition of a sequence of numbers, written with a plus sign between them or with the symbol Σ (sigma).

3 + 4 + 5 + 6 is a summation. Its result, 18, is the sum.

The compact form uses Σ and an index. For the same numbers:

  ∑ₖ₌₃⁶ k = 3 + 4 + 5 + 6 = 18

Here k runs from 3 through 6, and each value of k is added.
