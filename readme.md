# README.md

A readme markdown file about "summation":

```
4 + 5 + 6 is a summation (a sum).

The numbers 4, 5, 6 form an arithmetic sequence, so the summation is an arithmetic series. Its value is 15.

A summation is the addition of a list of numbers. The result is called the sum.

4 + 5 + 6 is a summation, and the sum is 15.

The same idea is written with Σ (sigma):

  ∑ₖ₌₄⁶ k = 4 + 5 + 6 = 15

k takes each whole number from 4 through 6, and those values are added together.
```

## What is the editor saying, "tab for autocomplete" ?
```
The editor is telling you how to accept the suggestion it is already showing.

When you see a gray “ghost” line of code, a highlighted item in a completion list, or a small hint like
“Tab for autocomplete”, it means:

The editor has predicted the rest of the word, line, or edit.
Press Tab to insert that prediction.
Press Esc (or just keep typing) if you don’t want it.
That is the same “tab autocomplete” idea as in a terminal, just applied to code:
Tab completes instead of inserting a tab character (while a suggestion is visible).

After you accept, some editors (especially Cursor-style “Tab”) treat the next Tab as
“jump to the next place you’ll edit.” If no suggestion is showing, Tab
usually goes back to its normal job: indent.
```
